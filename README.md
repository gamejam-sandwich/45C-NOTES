# Cloning the repo
Same steps as our homework repos! But feel free to use an IDE, I don't know if this code will survive vim...

If a quiz is not present, make sure you git pull (I make changes **every Monday** after I take the reading quizzes)

# Opening the quiz website
Open **quizzes/index.html** with Live Server or use integrated browser in VS Code.

# Updating the quizzes
You can add the quiz questions in JSON form yourself on your own copy of this repo (also add the _variables at the top of the index.html_ file).

If you're not familiar with HTML, then just **git pull** as stated above.

If you find errors, email me or make a PR and I'll merge it :-)
